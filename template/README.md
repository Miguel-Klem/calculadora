# 🖩 Calculadora Web Python

Este projeto é uma aplicação de calculadora web desenvolvida em Python com interface HTML, projetada para realizar operações matemáticas de forma simples e intuitiva.

## 📁 Estrutura do Projeto

A estrutura de arquivos do repositório está organizada da seguinte maneira:
calculadora/
├── .git/                  # Controle de versão do Git
├── .gitattributes         # Configurações do Git para o repositório
├── calculo.py             # Script principal em Python (lógica de cálculo)
├── README.md              # Documentação do projeto
└── template/
    └── index.html         # Interface de usuário (HTML/CSS/JS)


### ✨ Diferenciais

**Leveza & Velocidade:** Interface limpa sem dependências pesadas de frameworks.
**Divisão de Responsabilidades:** Separação clara entre a lógica de negócio (calculo.py) e a camada visual (index.html).
**Lógica Robusta:** Validação de entradas e tratamento de erros matemáticos no backend.

## 🛠️ Tecnologias Utilizadas

**Python**: Responsável pelo processamento e lógica dos cálculos (calculo.py).
---
**HTML/CSS/JS**: Interface web interativa (template/index.html).
---
**Git**: Controle de versão.
---

## 🚀 Como Executar o Projeto

### Pré-requisitos

Python 3.x instalado em sua máquina.

### Passos para execução

1. **Clone o repositório:**
   bash
   git clone <URL_DO_SEU_REPOSITORIO>
   cd calculadora
   

2. **Execute o arquivo principal em Python:**
   bash
   python calculo.py
   
3. **Acesse a aplicação:**
   Acesse a interface web abrindo o arquivo template/index.html em seu navegador ou pelo endereço local fornecido pelo script Python no terminal.

## 📝 Funcionalidades

➕ **Operações Aritméticas Básicas:** Soma, subtração, multiplicação e divisão.
🎨 **Interface Web Amigável:** Layout simples, limpo e responsivo.
⚡ **Backend em Python:** Processamento rápido de cálculos com tratamento de exceções (como divisão por zero).
