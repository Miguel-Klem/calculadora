# Calculadora

Este projeto contém uma calculadora completa em HTML/JavaScript e uma versão em Python para avaliação segura de expressões matemáticas.

## Como usar

### Calculadora no navegador
- Abra o arquivo `index.html` em um navegador.
- Use os botões ou o teclado para realizar operações.

### Calculadora em Python
- Execute o arquivo `calculo.py` com Python:

```bash
python calculo.py
```

### Operações suportadas
- Adição, subtração, multiplicação e divisão
- Porcentagem
- Decimais
- Parênteses
- Expressões com números e operadores básicos

## Exemplo

```text
Entrada: 5 * (10 - 3)
Resultado: 35
```
